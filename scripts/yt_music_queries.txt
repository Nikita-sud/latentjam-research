# Search queries for ytm_opus.py bulk collection.
#
# Each non-empty non-# line is either:
#   - "<artist> <song>"        → top 1 result for that specific track
#   - "<artist> <album>"       → tracks of that album (use sparingly)
#   - https://music.youtube.com/playlist?list=...   → playlist entries
#
# Guidance:
#   ./scripts/ytm_opus.py --from-file scripts/yt_music_queries.txt \
#     --search-limit 1 --max-tracks 5000
#
# With --search-limit 1, each line resolves to ~1 unique track (sometimes
# more after dedup if the top result is a re-upload). Expect ~85-95% of
# lines to materialize as files; the rest get dropped by duration filter,
# title dedup, or yt-dlp errors. ~1500 queries → ~1300-1400 tracks.
