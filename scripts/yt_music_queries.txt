# Search queries / playlist URLs for ytm_opus.py bulk collection.
#
# Each non-empty non-# line is either:
#   - "<artist> <song>"           → top-N matches for that specific song
#   - "<artist> <album>"          → tracks of that album
#   - https://music.youtube.com/playlist?list=...   → all playlist entries
#   - https://www.youtube.com/playlist?list=...     → same
#
# **Important**: queries like "best phonk 2024", "<genre> playlist", "<genre>
# songs 2024" return *compilation videos* (30 min – 12 h) on YouTube search,
# not individual tracks. The default --max-duration=900 will filter them out
# but you'll end up with zero downloads. Use specific artist+track queries
# OR paste real playlist URLs (which expand entry-by-entry).
#
# Recommended:
#   ./scripts/ytm_opus.py --from-file scripts/yt_music_queries.txt \
#     --search-limit 5 --max-tracks 5000
